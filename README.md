# TDE 01 — Calculadoras matemáticas

Abra `TDE01.sln` no Visual Studio 2026 com .NET 10 e workload .NET MAUI. Defina o projeto desejado como inicialização e execute no Android ou Windows.

- **CalculadoraDistancia**: calcula a distância euclidiana entre dois pontos.
- **CalculadoraBhaskara**: calcula Delta e as raízes reais de uma equação quadrática.

Ambos os apps validam campos vazios, números inválidos e possuem botão Limpar.

## Testes manuais
- Distância: (0,0) e (3,4) → 5.
- Bhaskara: a=1, b=-5, c=6 → Δ=1, raízes 3 e 2. Testar também (1,2,1), (1,0,1) e a=0.
- Compilação e execução no dispositivo ainda precisam ser verificadas.
